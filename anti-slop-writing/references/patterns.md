# Slop pattern catalog

Full reference for the anti-slop-writing skill. Each section shows the pattern, why it reads as machine-generated, and a rewrite. Read this before drafting any text longer than a paragraph.

## 1. Typography

The em dash aside is the single most recognized tell. Rewrite every occurrence.

Bad: `The platform — built on open standards — scales easily.`
Good: `The platform is built on open standards and scales easily.`
Good: `The platform (built on open standards) scales easily.`

Bad: `Tre pilastri — identità, autorizzazione, reputazione — reggono il sistema.`
Good: `Tre pilastri reggono il sistema: identità, autorizzazione e reputazione.`

Middle dots, arrows, and decorative symbols belong to slide bullets generated by machines. Use words.

Bad: `Fast · Secure · Open`
Good: `Fast, secure, and open.`

## 2. Antithesis pivots

The "not X, but Y" template creates fake profundity by denying a claim nobody made.

Bad: `This is not just a database, but a trust layer.`
Good: `The database records who attested what, so applications can treat it as a trust layer.`

Bad: `Non vendiamo software, vendiamo fiducia.`
Good: `Il software serve a una cosa sola: rendere verificabile chi ha fatto cosa.`

Bad: `It's not about speed; it's about reliability.`
Good: `Reliability matters more than speed here: a slow correct answer beats a fast wrong one.`

Related forms to catch: "less X, more Y", "X, not Y" as a closing beat, "più X che Y" as a flourish, "the real X is Y".

## 3. Punchlines, mottos, and dramatic closes

A one-line thesis set apart from the text, a pull quote, or a short dramatic sentence after two long ones all signal generated copy.

Bad: `We rebuilt the pipeline from scratch. We tested every edge case. It worked.`
Good: `We rebuilt the pipeline from scratch and tested every edge case; the new version has run without incident since March.`

Bad: `Bottom line: trust is the product.`
Good: delete the line. If the point was not made by the preceding text, fix the text.

Bad: `E questo cambia tutto.`
Good: delete. State the specific consequence instead: `Con questo vincolo, un agente compromesso perde le deleghe entro un minuto.`

## 4. Stock endings and recaps

Machine text summarizes itself. Human text stops.

Bad: `In conclusion, we have seen how identity, authorization and reputation combine to create trust.`
Good: end the document on the last substantive section, for example the open questions.

Bad: `In sintesi, la soluzione proposta offre numerosi vantaggi.`
Good: delete. If a summary is required by the format (an abstract, an executive summary), put it first, make it concrete, and do not repeat it at the end.

## 5. Participial result tails

A trailing "-ing" clause (or Italian gerund) that claims an outcome the sentence did not earn.

Bad: `The bridge writes attestations on-chain, ensuring trust across the ecosystem.`
Good: `The bridge writes attestations on-chain. Programs that read them can verify an agent's mandate without contacting us.`

Bad: `Il servizio valida le credenziali, garantendo la massima sicurezza.`
Good: `Il servizio valida firma, scadenza e revoca di ogni credenziale prima di accettarla.`

The fix is always the same: either state the outcome as its own sentence with its own evidence, or cut it.

## 6. Stock vocabulary, English

Replace by saying the specific thing.

| Slop | Instead |
|---|---|
| leverage | use |
| seamless | name what the user does not have to do |
| robust | name what it survives |
| cutting-edge, revolutionary | name what is new, with a date or version |
| unlock, empower, elevate | name the action now possible |
| delve into, deep dive | examine, or just start examining |
| navigate the landscape | name the actual choices |
| journey | process, project, or nothing |
| it's important to note that | delete, then state the fact |
| a wide range of | count them or name three |
| testament to | evidence of, or restructure |
| foster, harness | name the mechanism |

## 7. Stock vocabulary, Italian

| Slop | Instead |
|---|---|
| anche se (connettivo riflesso) | ma, però, oppure due frasi |
| è importante notare che | eliminare e affermare il fatto |
| in un mondo sempre più digitale | eliminare l'intera frase di apertura |
| senza soluzione di continuità | dire cosa l'utente non deve fare |
| all'avanguardia, rivoluzionario | dire cosa c'è di nuovo, con data o versione |
| punto di svolta | dire cosa cambia, in concreto |
| sfruttare (figurato) | usare |
| navigare il panorama | nominare le alternative reali |
| plasmare | definire, decidere, costruire |
| cruciale, fondamentale (riflesso) | dire cosa succede senza |
| un ventaglio di | contare o nominarne tre |
| a 360 gradi | elencare cosa copre davvero |

Note on "anche se": the word pair is legitimate Italian. The ban targets its use as an automatic concessive opener ("Anche se il mercato è competitivo, ...") where the concession adds nothing. Restructure: state the main claim, then the tension with "ma" if the tension is real.

## 8. Hedging and filler

Bad: `It could potentially be argued that this approach may offer some benefits.`
Good: `This approach cuts verification from three round trips to one.`

Bad: `Va detto che, in un certo senso, il sistema funziona abbastanza bene.`
Good: `Il sistema regge 400 richieste al secondo con errori sotto lo 0,1%.`

Cut intensifiers that carry no information: truly, incredibly, absolutely, davvero, assolutamente, estremamente. Keep hedges that carry real uncertainty ("the draft may change before ratification") because deleting honest uncertainty is its own failure.

## 9. Structure

Bulleted lists of bold mini-title, colon, sentence are the visual signature of generated documents. Write paragraphs. If the content is a true enumeration (a spec, a checklist, a table of options), a plain list or a table is fine.

Headers on a 300-word email, an Introduction section on a two-page memo, and a Conclusion that mirrors the Introduction all signal template filling. Short texts get no scaffolding.

Openers to delete on sight: "Great question", "Let's dive in", "In this post, we will explore". Start with the first fact.

## 10. Rhythm and register

The generated rhythm is long sentence, long sentence, three-word punch. Vary length naturally instead: let some paragraphs run even, let a short sentence land where the content is genuinely simple, and never place a fragment for drama.

Keep register consistent. A technical memo does not suddenly go lyrical in its final paragraph; that swerve is a tell.

## 11. Final self-check

Before delivering, verify: zero em or en dashes used as punctuation; zero entries from the vocabulary tables; zero antithesis pivots; no recap ending; no participial result tails; no bold outside headings and labels; bullets only where the user asked or the content is a true enumeration; the last sentence is content, and the first sentence is a fact.
